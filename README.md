### 5️⃣ ملف `restaurants.json` (بيانات الـ 236 مطعماً)
بسبب كبر حجم قاعدة البيانات التي تم جمعها (236 مكاناً حقيقياً بإحداثياتها)، عند فتح ملف `index.html` أعلاه في حاسوبك، سيطلب النظام جلب `restaurants.json`.
يمكنك تنزيل هذا الملف المكتمل بضغطة زر مباشرة من زر **`تصدير JSON`** داخل تطبيق الويب التفاعلي الذي يعمل لديك على `http://localhost:8000` أو نقله للمستودع! 🚀✨
