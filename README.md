# دليل مطاعم ومقاهي ولايتي أريانة وتونس (تونس الكبرى 🇹🇳)

تطبيق ويب تقدمي (PWA) وخريطة تفاعلية لجميع المطاعم والمقاهي في مختلف معتمديات ولاية أريانة وولاية تونس.

## 🚀 المميزات الرئيسية
- 📍 **قاعدة بيانات شاملة ودقيقة**: تغطي مطاعم ومقاهي ولاية أريانة (`restaurants.json`) وولاية تونس (`tunis_restaurants.json`).
- 🗺️ **خريطة تفاعلية أداء عالي**: تدعم التجميع الجغرافي للمواقع (Marker Clustering) والانتقال السلس بين الولايات والمعتمديات.
- 🌙 **وضع ليلي سلس ومتجانس**: تبديل مباشر لشرائح الخريطة إلى نمط CartoDB Dark Matter مع تحسين تصميم البطاقات والنافذة المنبثقة.
- 📱 **دعم تطبيق الويب التقدمي (PWA)**: إمكانية التثبيت والعمل بدون اتصال بالإنترنت مع التخزين المؤقت المتقدم عبر Service Worker.
- 🔍 **تصفية وبحث متقدم**: تصفية حسب الولاية، المعتمدية، نوع النشاط، السعر، التقييم، التوصيل والجلسات الخارجية.
- 📊 **تصدير البيانات**: دعم تصدير نتائج البحث إلى صيغ JSON و CSV.

## 🚀 تشغيل المشروع محلياً
```bash
python3 -m http.server 8000
```
افتح المتصفح على: `http://localhost:8000`
